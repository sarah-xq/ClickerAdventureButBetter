# AI Policy

AI is permitted, HOWEVER:

- Generated code from the AI is fine. If it does a mistake which messes up the code
YOU are solely responsible for the consequences.

- AI usage is preferred for tasks that are easily done but annoying to do. For example documentation

- Any AI is fine, however try not to use too many different types. Choose the one that works well with you

- Be transparent with your AI usage, don't pretend to know something that you didn't do, if it was done by AI, just say it

- Don't use AI for absolutely everything, this is a learning environment, do at the least the code yourself

- If you're truly stuck on something and neither does the product owner nor teammate know how to help, then turn to AI
